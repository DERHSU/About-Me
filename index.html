Football-Game

Explore the repository ↗

I built a football game for two players to compete in the browser.

Football-Game is a local two-player American football game built with HTML, CSS, and JavaScript. Players choose their teams and call offensive or defensive plays before each snap, then take control on the field.

The game uses HTML canvas to draw the action and includes passing, kickoffs, touchdown scoring, and a four-quarter game clock. It brings my interest in game development into a project people can play together on the same computer.
